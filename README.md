# dsh-haavk

DeepSeek Harness 的启动界面与启动动画插件。

**哈夫克全域互联终端**（《三角洲行动》哈夫克阵营开机画面）：浅蓝白斜切几何底 →
左列菱形徽记与 HAAVK 字标 → 右列标题与八行逐行点亮的系统清单 → 五步访问授权推进 →
分层退场 + 徽记落印 + WELCOME 交叉淡入 → 整片浅色场溶解回应用。

配色只用哈夫克蓝白（主蓝 `#2362af` / 亮蓝 `#5b96dd` / 深蓝 `#16324f`），
全站统一，不再有暖白与橙。

底板三档色（`--p-plane-t` / `--p-plane-m` / `--p-plane-b`）和斜切带
（`--p-facet-rgb`）不是估的：把参考画面切成网格逐格取色反解出来的 ——
上缘亮度约 215、蓝差 `b-r` 约 +27，中段 222 / +18，底部 230 / +7，
也就是整幅只在纵向上走一道很缓的「上冷下暖、上深下浅」，横向几乎不渐变。
横向再加强一点就会读成一张渐变卡，而不是真实终端画面。

## 功能

**开机序列**　冷启动时播一段完整的开机动画：终端画面淡入 → 八行系统清单按五步授权
逐行点亮 → 底部 `55ms` / `CN UID` 状态条与全宽细进度线同步推进 → 收尾。
清单文案：正在遍历员工级别矩阵 / 正在启动员工效率监控系统 / 正在校准全域信号阵列 /
正在预热脑机接口 / 正在计算可接受损失 / 正在抑制不必要变量 /
每一秒，都在投资未来…… / 请稍候，进一步需要时间……

**全程都在动**　没有一处是「开关式」显隐：徽记 1.4s 描边后落墨、外圈虚线环 34s 慢转、
字标逐字母升起、清单逐字浮出、刚点亮那行带光标、进度条用 rAF 追值（只进不退）且两幕之间
有渗流补帧、`55ms` 读数逐帧压到位、八行十六进制数据流滚动扫过、全场还有一道极缓的扫描光带。

**过渡不留硬切**　这一版专门治「每一处过渡都像切屏」：
徽记描边跑完后不是直接变实心，而是 `fill-opacity` / `stroke-width` 各自过渡 900ms，
线框与实心并存那半秒正是「墨顺着轮廓渗进去」；
状态条与计数换字时旧字就地变残影飘走、新字新建元素浮上来（不再清空重排）；
数据流换内容也不重启动画，滚动接着走，不会每步「跳回顶部」。
所有逐帧动画只碰 `transform` / `opacity`（状态格原本动画 `background`，已改）；
常驻无限动画不再挂 `will-change`，合成层不会越积越多。
实测 949 帧的进度采样里，最差一帧 16.8ms —— 没有超过 16.8ms 的帧。

**徽记更大，空白有人填**　徽记从 38vh 放大到 46vh（`clamp(230px, 46vh, 520px)`），
字标同档放大，光晕改用独立径向层（不再用 `drop-shadow` 滤镜，滤镜每帧重算最贵）。
原先空着的地方补进来：左下 `LINK SIGNAL` 实时波形、右下 `NODE MATRIX` 状态格、
贯穿全底的滚动播报带、徽记背后的雷达扫描弧与缓慢旋转的虚线环。

**退场是「换景」，不是「消失」**　内容整体包在 `.dsu-t-stage` 里，退场时这一层
缓慢推近到 1.035 并淡出（背景斜切面与网格不动）→ 有空间深度；
同时 `.dsu-t-finale` 的同心环、十字准星、上下两道读数线先淡进来占住画面，
WELCOME 落进去时不会掉进一片空场。徽记退到七成时 WELCOME 已经开始起，
两者擦身而过而不是先后登场。

**结尾收得住**　八行全亮后停一拍，清单与标题分层退场（每行错开 40ms），
徽记做一次缓慢「落印」呼吸，随后与 WELCOME 版式交叉淡入，最后整片浅色场
以 720ms 曲线溶解回应用。全程不缩放、不失焦 —— 全屏浅底上的模糊会显脏。

**原版读数全部留着**　上一版那套 HUD 没有丢，只是换成了哈夫克配色继续用：
左上品牌块（HAAVK / INFINITE INFORMATION / HAAVK GROUP）、下面 `REV 0.1.0 · WEB PROFILE`
加实时时钟、那一排阶段格、四角机框、暗角、档案水印、右上 `SKIP ▸`、右下 `POWERED BY HAAVK`，
以及状态条里的 `[ 05 / 06 ] VERIFY` 计数（每一步跟着跳）。散场时它们和清单一起分层收掉，
不是被一刀切掉。

**原生启动壳也同源（1.7.0 起，1.8.0 同步修版式）**　桌面端在网页层之前还有一层插件注入不进去的原生画面
（`Resources/splash.html`，原本是白底黑鲸鱼）。这一版把它重写成同一套哈夫克蓝白：
同一个 `MARK_PATH` 菱形、同一组 `--p-*` 变量、同样的描边 → 落墨 → 字标逐字母上浮，
四角刻度、右侧标尺、底部 `[ 03 / 03 ] LOAD · 47ms · CN UID · 状态条` 与细进度线全都在，
另外补了右侧 `BOOT SEQUENCE` 阶段表（逐行点亮）、左下 `LINK SIGNAL` 波形、
右下 `NODE MATRIX` 状态格。`safe-mode` / `plugin-recovery` / `web-import`
三张原生页也一起从纯中性灰换成哈夫克色板。文件放在仓库 `desktop-shell/`，
覆盖办法见 [DESKTOP.md](DESKTOP.md#五原生启动壳170-新增)。
1.8.0 把这一层也跟着修了：右侧标尺原来被写成一根实心柱子（渐变方向用错），
`NODE MATRIX` 又和标尺压线，两处一并改好；窄窗（≤1100px 或高度 ≤620px）
直接收起状态格，先保阶段表与标题。

**可交互，不是播片**　第一、二步要你点按钮或按 Enter 才会继续（可以关掉）。
右上角有跳过按钮，Esc 也能跳。

**中文主字 + 英文等宽副标题**　英文副标题逐字打出来，像终端在接收数据。

**真声台词 + 界面音效**　五句台词和终幕欢迎语都是真声素材，界面音效取自同一段素材。
浏览器要求先有一次点击才准出声，所以点过按钮之后才会听到声音。

**语音没播完不会推进**　每一步停留多久由实际音频时长决定。你点得快也不会把语音掐断。

**三十三项设置**　身份名称、编号、权限等级、配色、速度、音色、语速、
开口留白、每处文案……都能在设置页实时改，改完立即生效。

## 桌面端原生启动壳

桌面端（DeepSeek Harness Desktop）有两层启动画面：

| 层 | 文件 | 谁能改 |
|---|---|---|
| 网页层 | 插件注入的 `#dsh-startup-root` | 插件自己 |
| **原生层** | `Resources/splash.html` 等四张页 | 只能覆盖文件 |

原生层由 Electron 主进程 `showSplash()` 直接加载，插件注入不到，所以它在 1.7.0
之前一直是白底黑鲸鱼。`desktop-shell/` 里放的是已经改成哈夫克同款的四份文件
（`splash.html` / `safe-mode.html` / `plugin-recovery.html` / `web-import.html`），
复制进应用包的 `Contents/Resources/` 即可，具体命令、签名注意事项、以及
「桌面端自动更新会覆盖这四个文件」这条限制写在 **[DESKTOP.md](DESKTOP.md)**。

## 安装

**方式一 · 直接从本仓库安装**（推荐，拿到最新代码）

```bash
git clone https://github.com/YUNvexoxo/dsh-haavk.git
cd dsh-haavk
npm pack                                                  # 生成 dsh-haavk-1.8.0.tgz
dsh plugin --profile web add ./dsh-haavk-1.8.0.tgz
```

**方式二 · 从 Release 下载**　到 [Releases](https://github.com/YUNvexoxo/dsh-haavk/releases)
下载 `dsh-haavk-1.8.0.tgz`，然后 `dsh plugin --profile web add ./dsh-haavk-1.8.0.tgz`。

Windows 上也可以解压后**双击「安装.cmd」**，脚本会自动完成同样的操作。

**装完重启 dsh web**（关掉启动器窗口再重新双击）。重启后刷新页面就能看到启动动画，
设置页里会多出一项「启动动画」。

### 环境要求

| 项 | 要求 |
|---|---|
| 平台 | DSH **web** profile |
| Node | **>= 20** |
| 依赖 | 无（不需要 `npm install`） |

### 卸载

```bash
dsh plugin --profile web remove dsh-haavk
```

## 设置选项

装好后进入 **DSH 设置页 →「启动动画」**。

### 播放

| 选项 | 默认 | 作用 |
|---|---|---|
| 启用 | 开 | 总开关，关掉就完全不播 |
| 显示模式 | 每次会话 | `每次会话` 一个浏览器会话播一次 / `总是` 每次刷新都播 / `每天` 一天一次 |
| 主题 | 浅蓝 | `浅蓝` 哈夫克终端原色 / `暗色` 深蓝底板（同一套版式，只换底板与字色） |
| 速度 | 1× | 整段动画的快慢，0.35 – 3 倍 |
| 要求确认 | 开 | 第 1、2 步是否等你点按钮才继续 |
| 允许跳过 | 开 | 是否显示右上角跳过按钮、是否响应 Esc |

### 身份资料

| 选项 | 默认 | 作用 |
|---|---|---|
| 身份名称 | `哈夫克` | 终幕「欢迎 xxx 访问」里的名字 |
| 身份编号 | `HAAVK-01` | 身份核验用的编号 |
| 权限等级 | `4` | 权限等级读数 |

### 语音

| 选项 | 默认 | 作用 |
|---|---|---|
| 语音播报 | 开 | 是否念台词 |
| 语音来源 | 真声素材 | `真声素材` 用内置录音 / `系统 TTS` 用浏览器合成音 |
| 音色 | 自动 | 只在用系统 TTS 时有效。留空 = 自动挑一个女声 |
| 语速 | 0.88 | 只在用系统 TTS 时有效。越慢越有旁白感 |
| 音调 | 0.85 | 只在用系统 TTS 时有效。调低更沉稳，1.0 以上会像客服播报 |
| 音量 | 0.9 | 台词音量 |
| 播报前提示音 | 开 | 念台词前先响两声轻提示，更像系统播报 |
| 开口前留白 | 240 ms | 提示音响过之后停多久再开口，0 – 1200 ms |

### 文案
